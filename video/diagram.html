How Doomscroll Autopsy works

One pipeline, entirely inside the browser
Perceive
Page you scrolltext and a screenshot, read on the page; never stored
→
30 s bins + samplesIndexedDB: vectors and metadata, no item text, 30-day retention
→
EmbeddingGemma 2on-device, WebGPU, 256-d vectors, about 16 ms per item
Understand
and act
Territoriesyour own k-means clusters, labelled Deep, Shallow or Drain
→
Rabbit-hole predictionrules, then Markov, then GRU, each only if it beats the last
→
Nudge ladderbanner, then blur, then a 30 s breathing pause
Explain
Daily factsdeep blocks, switches, drains, nudge outcomes
→
Gemma 3 270Mfine-tuned: names and autopsy
→
Validatorsnumbers must match the facts, else a template writes it
→
Dashboardtimeline, map, autopsy, controls
Nothing you browse leaves your laptop. Only the one-time model download uses the network.
