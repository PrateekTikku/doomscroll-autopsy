## Understanding
Make the product complete without the fine-tune (Showcase L3): compute the day's facts deterministically from stored bins, render them as a coach-voice template autopsy (the permanent fallback for M6), show them in a timeline dashboard and the popup, and ship every Must privacy control (forget range/site, wipe, blocklist editor, retention, titles toggle) with the PDD 11.4 cascade. Unlocks L3.

## Approach (in order)
1. **`lib/metrics/` pure core.**
   - `time.ts`: local day window, `HH:MM`.
   - `facts.ts` `computeFacts({date, bins, territories, nudges, previous})` → `DailyFacts`.
     - Bin state: `deep|shallow|drain|other` from `effectiveLabel` (confirmed, else suggested, as scoring does). A bin is *browsing* if `!away && active_s > 0`; its clock contribution is `active_s`. Everything else (away, idle, missing bins) is a **gap**: it pauses the clock and is never reported (D-45).
     - **Deep block:** run over browsing bins; non-deep stretches ≤ 120 s (exactly 2 min allowed) stay inside the block; a longer one closes it at the last Deep bin; trailing interruption is excluded; qualifies at ≥ 1500 s of browsing time between first and last Deep bin. A gap longer than 30 min ends a block (**D-55**; shorter gaps pause the clock). Blocks belong to the day they start in (midnight-crossing blocks are kept whole). The caller loads bins from 3 h before to 3 h after the day.
     - **Residue:** a switch is a Deep bin followed by the next browsing bin labelled Shallow/Drain (unlabelled bins are not switches); `meanMinBackToDeep` = mean browsing time from switch to next Deep bin (returns only; null if none).
     - Totals by label (browsing minutes, whole numbers), drain over allowance per territory (`allowanceMin ?? 15`, only ≥ 1 min over), top triggers (from, to, local hour; ≤ 5 by count), strongest stretch (longest uninterrupted Deep run; territory with most time), nudge outcomes (unanswered = ignored; median return of accepted), `vs7Day` from the 7 stored reports before the date (null if fewer; deltas to one decimal).
   - `autopsy.ts` `renderAutopsy(facts)`: deterministic sentence builder following PDD 4.6 (headline, strongest stretch + totals, triggers/overage, nudges, one suggestion for tomorrow). Always 120–180 words (optional sentences by priority, neutral fillers when short), numbers only from facts, correct direction for the 7-day comparison, never any time outside the browser.
   - `validate.ts`: TypeScript port of T1's `check_autopsy` (the shared validator M6 reuses; it fixes the K-01 problem by being hand-written). The template must pass it on every fuzzed facts object.
   - `timeline.ts`: pure model for the chart: lanes per territory, merged segments, 5-min velocity points, deep-block ranges, nudge markers, visible range.
   - `service.ts`: DB loading (`buildDayFacts(date)`), `getOrCreateReport`, `ensureReports` (backfill missing past days in order so `vs7Day` works), `popupSummary`, 7-day success metrics.
2. **Nightly job** (`lib/metrics/background.ts`, registered as one line in `background.ts`): 30-min alarm; when a 03:00 boundary passed since the last run: retention → re-cluster if due (reuses M3 logic) → sync → facts + template autopsy for every missing past day, yesterday last → store in `reports` (`modelVersion: "template"`). Run state in `models/nightly-meta`. Also a `report-regenerate` message for "Generate now".
3. **Privacy** (`lib/privacy/`): `forget.ts` (range, site), `wipe.ts`, `retention.ts`, `messages.ts`, `background.ts` (handlers run in the service worker so they serialise with sync/re-cluster).
   - **Forget range/site cascade:** delete samples (by `ts` index / by `origin` host or subdomain), delete bins overlapping them (site forget: bins covered by the removed samples' dwell), delete nudges in range → recompute centroids/size of affected territories from remaining vectors → drop emptied unconfirmed territories (confirmed ones stay dormant, D-53) → rename unconfirmed baseline names → regenerate reports for affected dates → refresh Markov → write `forgetLog` (kind + range/site only). "Always skip" adds the domain to `settings.blocklist.addedDomains`.
   - **Wipe everything:** all IndexedDB stores, Cache API (model cache), `chrome.storage.local`/`session` (settings reset to defaults), then unload the embedder.
   - **Retention:** delete samples/bins/nudges/recorder events/reports older than `retentionDays` (nightly + when the setting changes). **Store titles off:** setting + a "remove stored titles now" action.
4. **Dashboard** (`entrypoints/dashboard/`): `main.tsx` gets a nav and the new sections; new `today.tsx` (metric tiles, history picker, success metrics, 7-day trend), `timeline.tsx` (plain SVG, **no D3 dependency**, D-56), `autopsy.tsx` (view, "Generate now", source label), `privacy.tsx` (forget range with 20 min/1 h/today/custom, forget site with always-skip, blocklist editor, retention, titles toggle, wipe with typed confirmation). Territories, Replay, Evidence, Developer unchanged.
5. **Popup:** a "Today" block: deep blocks (count + longest), attention residue, drain over allowance, nudges that worked (PDD 4.4), polled every 10 s.
6. **Evidence & verification:** `npm run eval:m5` (gated Vitest) replays the six persona synthetic days through the real pipeline, computes facts and autopsies into `docs/showcase/M5/`; `npm run probe:m5` (headless Chrome: seeds a synthetic day into the real extension DB, opens dashboard and popup, checks the timeline renders, runs a forget flow, takes screenshots, fails on exceptions).

## Test plan
- Unit: deep-block edge cases (interruption exactly 2 min vs 2 min 30 s, away gap pausing the clock, gap > 30 min ending a block, block across midnight, 24 min vs 25 min), residue (returns, no returns, unlabelled), allowance overage, nudge outcomes, `vs7Day` (null < 7, direction), facts validate against `daily-facts.schema.json` (Ajv in tests), template fuzz (word count 120–180, `checkAutopsy` clean, 7-day direction, all null/zero cases).
- Forget cascade on fake-indexeddb: samples/bins removed, centroid and size recomputed, emptied territories handled, report regenerated, forgetLog has no content; site forget + always-skip; wipe empties everything; retention.
- **Grep-style test:** scans UI/template source strings and runs the template for time-outside-browser phrases (reusing the T1 pattern).
- Privacy store-scan test extended to `reports`/`forgetLog`.
- `npm run build && test && compile && smoke && check:types`, `probe:m5`, `M3=1 probe:s1`, `probe:m4` as regression.

## Risks and open questions
- Real-data timeline for the owner's profile can't be seen by me; mitigated by the seeded headless dashboard and screenshots.
- Bin territories lag ≤ 1 min (K-16): today's numbers are always slightly behind; the dashboard runs a sync before computing.
- Idle threshold (K-06) means ≤ 120 s at the start of an idle stretch counts as active; stated, not changed.
- Hand-rolled SVG instead of D3 is a deliberate deviation (smaller bundle, no new dependency).
