# M3: what to capture (owner, ~10 min)

Do this after `npm run live`, reload the extension, and a few hours of normal browsing (you need about 300 embedded items for the automatic first run, or 60 for the button).

1. **Dashboard → Territories, unlabelled**: the list right after the first clustering (names like `youtube.com · shorts`, sizes, top origins, today's minutes, dashed "suggested" outline on a label).
2. **Labeling**: click Deep / Shallow / Drain on three territories; set a Drain allowance. Screenshot with the "confirmed" lines.
3. **Re-cluster now**: press it once; screenshot the status line ("N clusters from M items … K kept, 0 new") and the same list afterwards: same names, same labels.
4. **The "one domain, many territories" shot**: Dashboard → Developer → turn on dev mode, then "Compute evidence". Capture the example table (e.g. YouTube split into a Deep tutorial territory and a Drain Shorts territory), and read the JSON before using any of it in the post.
5. Optional GIF: browse Shorts then a tutorial video, press "Re-cluster now", watch the two territories separate.
