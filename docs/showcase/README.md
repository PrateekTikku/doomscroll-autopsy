# Showcase material

Every milestone saves evidence for the DEV post in `docs/showcase/<milestone-id>/` (e.g. `docs/showcase/M3/`):

- **Numbers and notes** as short Markdown or JSON files: measurements, comparisons with baselines, examples.
- **`CAPTURE.md`**: the screenshots or GIFs the owner should take, each with where to click and what should be visible.

Rules:
- Never put real item text, screenshots of private pages or query strings here (PDD 11). Use replayed or synthetic days when in doubt.
- Keep claims honest: say when a number comes from a replay or synthetic data.
- M9 builds the post from this folder (`implementation-milestones.md` M9).
